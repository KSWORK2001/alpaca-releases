Everything a local runtime should be.

One gateway process supervises the model server, the chat UI, two API dialects and web search — so switching models, downloading new ones, or wiring up your apps never means restarting anything by hand.

🖥️

A chat UI you'd actually use

ChatGPT-style layout with history sidebar, streaming markdown, image understanding, and per-conversation web search. LM Studio-depth generation settings when you want them.

⚡

Tuned for Apple Silicon

MLX under the hood: MTP speculative decoding (lossless), bounded KV cache for 262K-context models, continuous batching, and a wired-memory advisor for big quants.

🔍

Web search, built in

DuckDuckGo with page extraction, no API key. The model calls search as a tool and cites what it used — or force-ground every answer in fresh results.

📦

Any model, one click

Download from Hugging Face (gated repos too), switch at runtime, delete when done. Cached models are scanned and MoE models flagged automatically.

🐢

Playground: bigger than RAM

Repack a huge MoE model so experts page from your SSD via mmap + LRU, and run checkpoints that shouldn't fit. Loud, honest warnings included.

🤖

Built for agents first

Every CLI command speaks JSON, exits with a strict code contract, and capabilities self-describes the whole surface. Ollama has nothing like it.

Speaks both dialects.

Point OpenAI clients at the /v1 endpoint, or set OLLAMA_HOST and every Ollama integration just works. Vision, tools, streaming and sampling parameters pass straight through to the model.

Python — OpenAI SDK
from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:8080/v1",
                api_key="unused-on-loopback")
r = client.chat.completions.create(
    model="alpaca",
    messages=[{"role": "user",
               "content": "summarize this"}])
Shell — any Ollama client
export OLLAMA_HOST=http://127.0.0.1:8080
ollama list
ollama run qwen "hello"

# or native API
curl localhost:8080/api/chat -d '{
  "message": {"role": "user", "content": "hi"},
  "web_search": "force"
}'

A CLI agents can drive.

Machine-readable everywhere: --json on every command, exit codes 0/1/3/4 you can branch on, --wait flags that block until the model is ready — and a self-describing capabilities command, so an agent discovers the interface without reading docs.

 alpaca — zsh
$ alpaca capabilities --json          # agents start here
{ "commands": [ {"name": "status"}, {"name": "chat"},
    {"name": "models"}, {"name": "playground"}, … ],
  "exit_codes": {"0": "ok", "3": "gateway unreachable",
                 "4": "model not ready"} }
$ alpaca models switch org/model-8bit --wait
model ready: org/model-8bit
$ alpaca chat "what shipped in mlx this week?" \
      --search force --json
{ "content": "MLX 0.33 shipped…", "usage": {…} }
$ alpaca update --apply               # self-upgrade
updated 0.1.2 → 0.2.0

Playground 🐢 — models bigger than your RAM.

Repack a routed-MoE checkpoint and Alpaca streams its experts from your SSD through mmap with an LRU budget — so a model that shouldn't fit can still run. Honest numbers from a 48 GB machine:

~2 minto repack an 8 GB checkpoint
cold: slowfirst prompt pages experts from SSD
35 tok/swarm — resident after first touch
⚠️ This is a playground for models you couldn't run at all otherwise — unbearably slow cold, permanently slow for truly huge sets. Alpaca will tell you so at every step.

Your machine. Your models. Your data.

Alpaca binds to loopback by default and talks to nobody but you — and the model sources you choose.

🔒

Loopback first

Everything on 127.0.0.1 with a generated API key; expose to your LAN only if you deliberately choose to — then the key is mandatory.

💬

Chats stay home

Conversations live in a local folder. No telemetry, no accounts, no cloud.

🔑

Your HF account

Downloads use your Hugging Face token when a repo needs one — stored locally, used for pulls only.

🌐

Search on your terms

Web search runs from your machine, per conversation: auto, forced, or off.

Get Alpaca.

macOS on Apple Silicon with Python 3.12+. The installer checksum-verifies everything, sets up the environment, and puts alpaca on your PATH.

curl -fsSL https://github.com/KSWORK2001/alpaca-releases/releases/latest/download/install.sh | bash
